# Hades II Keepsake Tracker

A simple self-hosted web app to track which **Hades II keepsakes** you’ve collected.  
Each god is shown as a card you can click to mark as collected. Progress is saved locally with cookies — no accounts or servers needed.

## Features
- All keepsakes grouped by their respective gods  
- Click cards to toggle collected status  
- Progress auto-saves in browser cookies  
- Fully offline and self-hostable

## Usage
1. Use the Github hosted page
2. Click on a god’s keepsake card to mark it as collected  
3. Your progress stays saved automatically

##If wanting offline mode
1. Clone the project
2. Open index.html on any browser
3. Click on a god’s keepsake card to mark it as collected  
4. Your progress stays saved automatically

## Tech Stack
- HTML, CSS, JavaScript  
- Cookies for local data persistence  
- Customizable keepsake data in `data.js`
